# 冷蔵庫の期限管理 試作品 v0.1

## 含まれる機能
- 食品名、JANコード、賞味/消費期限、保管場所、数量、メモの登録
- USB/Bluetoothのキーボード入力方式バーコードリーダーからの入力
- 対応ブラウザでのカメラバーコード読み取り（BarcodeDetector）
- 写真を使ったOCR日付候補読み取り（Tesseract.js、日本語＋英語）
- 期限までの日数、期限間近（3日以内）、期限切れの表示
- 検索、フィルター、編集、消費・削除
- JSONバックアップと復元

## Androidタブレットでの起動
カメラ機能はブラウザのセキュリティ上、HTTPSまたはlocalhostで開く必要があります。
1. ZIPをPCで展開するか、Webサーバーに配置します。
2. `index.html` をHTTPSで公開します（例：自分のレンタルサーバー、社内/家庭内のHTTPS対応環境）。
3. AndroidタブレットのChromeでURLを開き、カメラ権限を許可します。
4. Bluetooth/USBバーコードリーダーは「キーボード(HID)モード」に設定し、JAN入力欄にカーソルを置いて読み取ります。

単純にファイルをタップして開く方法では、カメラ機能が利用できない場合があります。
OCRライブラリの初回読み込みにはインターネット接続が必要です。

## 重要な制約（試作品）
- JANコードだけでは個別商品の賞味期限は分かりません。期限はパッケージを撮影してOCR候補を出し、利用者が確認する設計です。
- 商品名の自動照会データベースは未接続です。初版では商品名を手入力します。
- データは端末内のブラウザ保存領域（localStorage）に保存されます。ブラウザデータ消去で失われる可能性があるため、定期バックアップが必要です。
- 通知、家族間同期、クラウド保存、複数ロット管理、開封後期限、レシート連携は未実装です。
- OCRは日付を誤認識する可能性があります。登録前に必ず確認してください。
